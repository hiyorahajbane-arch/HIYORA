=========================================================
   DARIYA ACADEMY  -  How to use it
=========================================================

STEP 1
   Double click the file  START_HERE.bat

STEP 2
   Wait. The first time takes a few minutes because it
   downloads the programs it needs. Every other time it
   takes a few seconds.

STEP 3
   Your web page opens by itself. Nothing to click.

STEP 4
   Log in with:

        email : demo@dariya.academy
        pass  : demo1234

STEP 5
   Keep the black window open while you use the site.
   When you are done, click the black window and press
   CTRL + C to close the site.


---------------------------------------------------------

     - examples you can listen to
     - exercises

   You can also speak and the app checks you.


---------------------------------------------------------
  IF SOMETHING GOES WRONG
---------------------------------------------------------
   The black window tells you what happened. Read the
   red [X] line, it says what to do.

   "Node.js is not installed"
       Go to https://nodejs.org and install the big
       green LTS button. Then double click again.

   "No free port between 4000 and 4020"
       Close other programs that might be using the
       internet, then double click again.

   The page does not open by itself
       The address is printed in the black window.
       Copy it and paste it in your browser.


---------------------------------------------------------
  OTHER THINGS START_HERE.bat CAN DO
---------------------------------------------------------
   Right click START_HERE.bat, choose "Run as
   administrator" is NOT needed. Instead open a
   command window here and type:

       START_HERE.bat test      check that all is fine
       START_HERE.bat reset     erase all my progress
       START_HERE.bat dev       for programmers only
       START_HERE.bat --no-open start without opening
                                 the web page
