# 🛍️ سوق — متجر إلكتروني كامل

متجر إلكتروني عربي بواجهة حديثة ويشمل **لوحة إدارة** كاملة.
التقنيات: **React (Vite)** للواجهة + **Node.js (Express)** للخادم + تخزين قائم على ملف **JSON**.

## المميزات

**المتجر (العملاء):**
- عرض المنتجات مع بحث وتصفية حسب التصنيف
- صفحة تفاصيل المنتج
- سلة مشتريات (إضافة/إزالة/تعديل الكمية)
- إتمام الطلب (الدفع عند الاستلام) مع تخزين بيانات الزبون
- رقم تتبع للطلب بعد التأكيد

**لوحة الإدارة:**
- تسجيل دخول للمشرف (JWT)
- إحصائيات (عدد المنتجات، الطلبات، الإيرادات)
- إدارة المنتجات: إضافة / تعديل / حذف / مخزون
- إدارة الطلبات: تغيير الحالة (قيد الانتظار → مؤكد → تم الشحن → تم التسليم / ملغي)
- إرجاع المخزون تلقائياً عند إلغاء الطلب

## التشغيل

> يتطلب Node.js 18 أو أحدث.

```bash
# 1. تثبيت كل الحزم
npm run install:all

# 2. تهيئة منتجات تجريبية
npm run seed

# 3a. وضع التطوير (محطتان)
npm run dev:server   # الخادم على http://localhost:3001
npm run dev:client   # المتجر على http://localhost:5173

# 3b. أو الإنتاج (بناء الواجهة ثم تشغيل الخادم بمفرده)
npm run build
npm start            # المتجر على http://localhost:3001
```

## بيانات الدخول للوحة الإدارة

- المستخدم: `admin`
- كلمة المرور: `admin123`

يمكن تغييرها عبر متغيرات البيئة `ADMIN_USERNAME` و `ADMIN_PASSWORD` قبل التشغيل.

## هيكل المشروع

```
├── server/          # خادم Express
│   ├── server.js    # نقطة الدخول
│   ├── seed.js      # تهيئة المنتجات التجريبية
│   ├── lib/db.js    # قاعدة البيانات (JSON)
│   └── routes/      # auth / products / orders
└── client/          # تطبيق React (Vite)
    └── src/
        ├── pages/        # المتجر والسلة ولوحة الإدارة
        ├── components/   # مكونات مشتركة
        └── context/      # حالة السلة
```

## ملاحظات

- البيانات تُحفظ في `server/data/db.json`.
- الدفع عند الاستلام حالياً — يمكن إضافة بوابات دفع (Stripe/PayPal) لاحقاً.
- لحذف كل البيانات: احذف `server/data/db.json` ثم أعد تشغيل السيد.
